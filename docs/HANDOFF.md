## После получения токена

В обычном терминале:

```sh
cd /Users/georgious/.codex/.chatgpt-projects/g-p-6a268e3dffa48191a87c95a752990450/intent-radar
npm run setup:token
```

Вставьте токен в скрытый ввод. Он сохранится в `.env.local` с доступом только владельцу файла. Не вставляйте токен в чат или в команду терминала. Скрипт не выполняет сетевых запросов. Секрет не попадает в браузер; запросы к Meta используют заголовок Authorization.

Перезапустите `npm run dev`. Откройте http://127.0.0.1:3100/, раздел «Подключение», нажмите «Проверить поиск». Альтернатива из терминала: `npm run collect`.

По умолчанию выбраны «нужна CRM» и «потрібна CRM». Первый поиск охватывает последние 24 часа в пределах доступной выдачи. Максимум — три выбранных запроса, две страницы каждого, локальный бюджет 100 обращений за скользящие 24 часа. Это ограничения приложения, а не опубликованные лимиты Meta.

## Что произойдёт при проверке

- Нет токена: никаких сетевых вызовов.
- Недействительный/истёкший токен: понятная ошибка, нужна повторная авторизация.
- Нет разрешения поиска: понятная ошибка, проверяем режим приложения и App Review.
- Лимит: пауза с учётом Retry-After, без бесконечных повторов.
- Есть публикации: сохраняются в SQLite, появляются в источнике «Threads · реальные», доступны реальные ссылки.
- Пустая выдача: успешный технический ответ, но не доказательство отсутствия спроса.
- Больше двух страниц: статус partial, контрольная дата не продвигается; нужен отдельный эксперимент с лимитами/окнами.

## Диагностика генератора Meta

Для первой проверки выбран georgio_puzanni. Штатный генератор запрашивает basic/publish/insights/manage_replies/read_replies без keyword_search. Отдельный запрос basic + keyword_search показал правильный экран согласия; владелец нажал продолжение, но токен не подтверждён. Переход в обычную вкладку мог нарушить возврат результата всплывающему генератору — это гипотеза. При повторе в штатном окне все четыре необязательных права отключены, выполнено продолжение с basic; окно закрылось, но получить состояние основной страницы не удалось из-за тайм-аутов управления Safari. Не считать токен полученным или поиск рабочим. Следующий шаг — осмотреть основное окно Meta на предмет диалога токена и затем проверить фактические scopes и API.

Нужна повторная генерация/точное копирование полного пользовательского маркера Threads и замена через setup:token. Реальных публикаций не получено.
