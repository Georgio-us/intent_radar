# Локальная эксплуатация и проверки

## Запуск

Node.js 22.17+ и npm. Встроенный node:sqlite пока выводит предупреждение ExperimentalWarning; дополнительных серверов базы не требуется.

```sh
npm install
npm run dev
```

Адрес: http://127.0.0.1:3100/. Сервер привязан к loopback, порт 3100. Настройки защиты запросов также рассчитаны на localhost/127.0.0.1:3100. Смена порта требует изменения локального списка разрешённых адресов.

## Что хранится

`data/radar.sqlite` — локальная база. Не удалять её для обновления кода. При старте выполняется идемпотентная SQL-миграция `db/migrations/001_collector.sql`. Старые отметки и пользовательские слова сохраняются, новые словари однократно дополняют существующие темы.

- settings: темы, потоки, запросы, пауза после лимита.
- feedback: ручная оценка по ID; одинаковые темы не дублируют публикацию.
- posts: ID, исходный текст, безопасная ссылка, время публикации, первого и последнего обнаружения; география проекта неизвестна.
- analyses: версия алгоритма, хеш словаря и текста, результаты; повторный анализ не меняет ручную оценку.
- query_runs: параметры окна и запроса, статус, счётчики и безопасное описание ошибки.
- post_query_matches: связь публикаций с запусками.
- checkpoints: последнее полностью загруженное окно каждого запроса.
- locks: аренда сборщика, исключающая одновременные циклы из CLI и веб-интерфейса.

В базу не сохраняются токен, полный URL HTTP-запроса и произвольный текст ошибки провайдера. Ошибки Meta отображаются через фиксированные сообщения. Перенаправления HTTP запрещены. Поле paging.next никогда не открывается: курсор подставляется только в фиксированный endpoint Meta.

## Правила сбора

До трёх запросов и двух страниц на запрос. Окно первого запуска — 24 часа; следующих полных запусков — от последней контрольной даты с перекрытием 10 минут. Частичные загрузки не продвигают контрольную дату. Для массовой исторической загрузки потребуется отдельная стратегия узких окон после изучения API. Задержки индексации за пределами перекрытия пока не компенсируются.

100 вызовов в сутки — собственный консервативный бюджет, не подтверждённая квота Meta. Повтор после ошибки вручную. После rate limit действует сохранённая пауза. Планировщик ещё не включён: API сначала нужно проверить.

## Языки, отрасли и оценка

Правила поддерживают RU/UK/EN/ES, unknown и mixed. Они приблизительны и могут ошибаться. Флаг other предусмотрен, но детектор не распознаёт все остальные языки. Слова «Meta» и «мета» не объединяются автоматически. Отрицания, сарказм, цитаты и несколько намерений в одном посте — известные ограничения.

География неизвестна. Код фильтра умеет обрабатывать явную страну проекта и unknown, но автоматически страну не присваивает; UI не обещает блокировку стран. Политика по умолчанию сохраняет неизвестные географию и язык. Отраслевая оценка основана на цитируемых словах, а не на профилировании автора.

## Разметка и backtest

Экспорт `data/annotation.jsonl` содержит `text`, `intent`, `industry`, `language`, а также отдельную `prediction`. Первые три поля разметки изначально null: их должен заполнить человек. Предсказание модели нельзя автоматически считать эталоном. Допустимые intent: contractor, solution, discussion, mention, offer, problem, unmatched. Industry: property, adjacent, unknown. Language: ru, uk, en, es, mixed, other, und.

`npm run evaluate` считает матрицу ошибок, precision/recall по категориям, результаты по языкам, ошибки отрасли и языка. Результат: data/evaluation.json. Скрипт не меняет правила сам. Синтетический набор — средство разработки, не независимый тест и не backtest Threads. Для реальной оценки разделить обучающую и отложенную выборки, исключить дубли между ними, отдельно оценить ложные отбрасывания.

## Ограничения первого локального этапа

Скринер показывает до 1000 последних сохранённых постов и сортирует их по правилу приоритета. Счётчики относятся к этой загруженной выборке. Отчёт сборщика хранит реальные объёмы вызовов и загрузки. Автоматических ответов, Telegram, периодического сбора, аккаунтов пользователей, внешнего хостинга и PostgreSQL нет.
