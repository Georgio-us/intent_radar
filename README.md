# Intent Radar · Reset

Локальный скринер публичного спроса: одна публикация на строку, подробности по нажатию. Недвижимость в приоритете; CRM, базы данных, автоматизация и сложная разработка подходят и для других отраслей.

## Запуск

Node.js 22.17+.

```sh
npm install
npm run dev
```

Открыть http://127.0.0.1:3100/. Только loopback; размещение в интернете не выполнялось.

## Готово локально

- Компактный скринер: фильтры источника, потока, языка и намерения; подсветка и ручные отметки.
- Шесть направлений, 78 поисковых гипотез RU/UK/EN/ES и четыре редактируемых потока.
- Отраслевой приоритет, простой языковой и смысловой анализ; неизвестные значения видны явно.
- SQLite, SQL-миграция, реальные публикации отдельно от демо, история анализов и журнал запросов.
- Ограниченный модуль поиска Threads: дедупликация, пагинация, перекрытие окон, бюджет, блокировка параллельных запусков, ошибки доступа/лимитов.
- Скрытый локальный ввод токена; нет секретов в интерфейсе, URL запросов или журнале.
- Экспорт для ручной разметки, повторный анализ и оценка на JSONL.

## Текущая внешняя зависимость

Реальный поиск ещё не подтверждён: нет проверенного токена Threads с доступом к keyword_search. Тесты API используют подставные ответы. Вымышленные примеры не являются реальными лидами. Следующий шаг — пользователь создаёт/выбирает приложение Meta и предоставляет доступ через официальный процесс; [точная инструкция](docs/HANDOFF.md).
